# GitCanvas releases

Builds of GitCanvas, a native desktop Git client.

Windows (PowerShell):

```powershell
irm https://github.com/TheCamer1/git-canvas-releases/releases/latest/download/install.ps1 | iex
```

macOS and Linux:

```sh
curl -fsSL https://github.com/TheCamer1/git-canvas-releases/releases/latest/download/install.sh | sh
```

Or download an archive from the [releases page](../../releases). Binaries are unsigned, so Windows SmartScreen and macOS Gatekeeper will warn on first run.
